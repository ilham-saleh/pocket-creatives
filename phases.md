# CRITICAL UPDATE: Exact Lumifya Design and Animation Recreation

## 1. Visual fidelity is the highest priority

I do NOT want a website loosely inspired by Lumifya.

I want the final Pocket Creatives website to match the **actual Lumifya template's visual design and observable interactions as closely as possible**, while using Pocket Creatives' own logo, services, projects, photography, videos and business information.

The target is high visual and behavioural fidelity, not a generic creative-agency redesign.

Inspect the live Lumifya preview using browser tools before implementing the design.

Match the following as closely as possible:

- Colour palette and background transitions.
- Typography, font sizes, line heights and letter spacing.
- Page layouts, grids, alignment and section spacing.
- Hero composition and media placement.
- Navigation and mobile menu.
- Button designs, hover states and transitions.
- Portfolio cards and image proportions.
- Section composition and footer.
- Desktop, tablet and mobile behaviours.

Do not invent a different creative direction.

Use original code and appropriately licensed assets rather than copying proprietary source code or paid template files.

## 2. Recreate the actual animations

Animations are a core requirement, not an optional enhancement.

Analyse the reference while interacting with it and scrolling through every section.

Create an **animation inventory** documenting:

1. Which elements animate.
2. What triggers each animation.
3. Whether it is time-based, hover-based or scroll-based.
4. Initial and final visual states.
5. Direction and distance of movement.
6. Approximate duration and easing.
7. Whether multiple elements animate in sequence.
8. Whether the animation reverses when scrolling backwards.
9. How the behaviour changes on mobile.

Recreate every observed, relevant animation using GSAP, ScrollTrigger, CSS or other appropriate techniques.

Pay particular attention to:

- Scroll-triggered typography reveals.
- Staggered text and image entrances.
- Scroll-linked transformations.
- Parallax effects.
- Pinned or sticky animated sections.
- Image masking and clip-path transitions.
- Hover-based image and card effects.
- Navigation transitions.
- Page transitions.
- Background changes during scrolling.
- Responsive animation variations.

Do not add random animations that are absent from Lumifya simply to make the website look more dynamic.

If an effect cannot be inspected or recreated accurately, document the limitation rather than silently substituting something unrelated.

Respect reduced-motion accessibility settings.
